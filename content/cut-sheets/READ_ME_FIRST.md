**READ ME FIRST**

*Kilkenny Farms West & Southbridge — Short-Form Video Cut Sheets*

**What this folder is**

These are “cut sheets” — instructions for an editor to build short vertical videos (Reels / TikToks / YouTube Shorts) from footage we already filmed in two Waunakee neighborhoods, Kilkenny Farms West and Southbridge. We shot the raw clips on June 16. These documents tell you exactly which clips to use and in what order to make six finished shorts. You do not need to film anything new.

**What’s in the folder**

Eight documents. Start with this README, then the “00 Master” for the big picture, then the six numbered cut sheets — one per video:

- 00 Master — overview, the full clip library, the short list, and thumbnail ideas.

- 01 — Kilkenny Farms West vs. Southbridge: Which One Is Actually You?

- 02 — If I Were Building in Kilkenny West

- 03 — Don’t Assume the Pool in Southbridge

- 04 — Ranking Waunakee’s Parks (From Someone Who Lives Here)

- 05 — More Than a Garage Door: Why Southbridge Feels Like a Community

- 06 — Southbridge Isn’t One Neighborhood

**How to use a cut sheet**

Pick a number, open it, and follow the timeline top to bottom. Each document gives you the point of the video, the exact clip files to pull from our Google Drive footage folder, a second-by-second timeline of what to show and when, the lines to keep, on-screen text, and a thumbnail idea. Every clip it names is a real file in the Drive footage folder — just match the filename. Each video ends the same way, with John’s call/text number on screen.

**Important — read the top line of each document**

Every file starts with a line marked “✔ CORRECTED.” These filenames were verified against the actual Google Drive footage on June 28, 2026. If the top line also says “FLAG,” that’s a small thing to confirm before publishing. The two to know about:

- Only ONE “Dunwoody” clip exists. Short 01 was written for two; both now point to the same real clip. Use a second establishing shot if you want variety.

- There is no “Park-Pavilion-Amenity-Close (Horizontal)” clip. Where it was called for, a real Southbridge pool/community clip is substituted.

- A couple of Southbridge on-camera shorts (05 and 06): confirm the clip that actually contains the spoken line, since several Southbridge on-camera files look similar.

**Two quick notes on the footage names**

Kilkenny clips start with “2026-06-16_Kilkenny-Farms-West…” Southbridge clips start with “2026-06-XX_Southbridge…” — they’re two different naming styles, but both live in the same Drive footage folder. If you want the full clip-by-clip map for any short, see “CORRECTED_Clip_Map_Real_Drive_Filenames.”

**The goal**

Six clean, captioned vertical videos — one per document — ready to post to social media. Questions on any neighborhood detail go to John.
