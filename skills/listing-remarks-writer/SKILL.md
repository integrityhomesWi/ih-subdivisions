# Listing Remarks Writer

Write MLS listing descriptions that are optimized for AI-powered home search. Buyers increasingly search for homes through conversational AI platforms (ChatGPT with Zillow, Perplexity, Google AI Overviews). These platforms can only read the text in a listing's public description — they cannot interpret photos, 3D tours, or captions. Every feature that isn't named in the remarks is invisible to AI search.

## Core Principle: Nouns Over Pronouns

AI search engines match buyer queries to listing text through nouns, verbs, and modifiers — not vague pronouns or generic filler. Every sentence should contain specific, searchable terms.

**Weak:** "This beautiful home has been lovingly updated throughout."
**Strong:** "Renovated 4-bedroom Colonial in Waunakee with quartz countertops, white oak hardwood floors, and a screened-in porch overlooking a fenced backyard."

The strong version contains 10+ searchable nouns. The weak version contains zero.

## Writing Framework

### Nouns (What it is and where it is)
- Property type: Colonial, ranch, Tudor, mid-century modern, contemporary, craftsman, split-level, two-story, Cape Cod
- Location: neighborhood name, subdivision, city (Madison, Sun Prairie, Waunakee, DeForest, Verona, Middleton), ZIP, proximity landmarks ("two blocks from Token Creek," "walking distance to downtown Waunakee")
- Features: specific materials, room names, upgrades, systems
- Nearby amenities: parks, trails, shopping, transit, restaurants — name them specifically

### Verbs (What it offers)
- Features, overlooks, includes, connects to, opens to, sits on, backs to, offers, provides

### Modifiers (What makes it searchable)
- Adjectives buyers actually search: renovated, updated, turnkey, open-concept, move-in ready, low-maintenance, energy-efficient, luxury, waterfront, cul-de-sac, private, fenced, walkable
- Avoid subjective fluff: stunning, gorgeous, amazing, dream home, must-see, nestled, boasts

## Structure

1. **Opening line:** [Property type] + [bed/bath] + [key differentiator] + in [specific location]
2. **Feature stack:** 3–5 sentences dense with searchable nouns. Prioritize kitchen, primary suite, outdoor space, and any standout feature. Name materials, brands, and upgrades specifically.
3. **Location context:** 1–2 sentences naming nearby amenities (without school quality ratings) and lifestyle elements. Be specific — "half a mile from Governor Nelson State Park" not "close to parks."
4. **Closing line:** Soft CTA or lifestyle framing that includes the neighborhood name one final time.

## Rules

- Front-load the description with the most searchable terms. AI platforms often truncate or summarize — the first 50 words carry the most weight.
- Name every room and feature that matters. If the home has a mudroom, a butler's pantry, a three-car garage — say so. If you don't name it, AI can't find it.
- Use the neighborhood or community name at least twice.
- Use the city and state at least once.
- Never fabricate features, square footage, or amenities.
- Comply with Fair Housing: no references to race, religion, national origin, familial status, disability, sex, or school quality/ratings.
- Respect the MLS character limit if specified. If no limit is given, target 250–500 words.

## Example

**Input:** 4 bed, 3.5 bath, 2,800 sqft, built 2018, Westbridge neighborhood in Waunakee WI, quartz counters, hardwood floors, covered patio, 2-car garage, near Pheasant Branch

**Output:** "Modern 4-bedroom, 3.5-bathroom home in the Westbridge neighborhood in Waunakee, Wisconsin. Built in 2018, this 2,800-square-foot residence features an open-concept main level with white quartz countertops, a gas range, a walk-in pantry, and hardwood floors throughout. The primary suite includes a tiled walk-in shower, double vanity, and a custom closet system. Three additional bedrooms share the second level alongside a full bathroom and a bonus room. The covered back patio overlooks a level, fenced backyard. A 2-car attached garage provides storage and direct entry to the mudroom. Westbridge residents enjoy easy access to the Pheasant Branch Conservancy trail system and downtown Waunakee restaurants and shops. Located in Dane County, Waunakee, WI 53597."
