## When This Skill Runs (vs. ROH Content Writer)

- **This skill**: source material is a **video transcript, recorded clip, interview, or detailed outline** to be repurposed across platforms. Output is production direction + platform deployment scripts.
- **ROH Content Writer**: source is a **written subject** (grant, hero spotlight, educational blog, profession page). Output is long-form HTML + Publishing Packet with its own social pack.

If the source is a transcript but the goal is actually a long-form blog, hand off to ROH Content Writer instead. If unsure, ask: "Do you want the multi-platform video pack, or a long-form blog/page?"

## Intake (Ask in One Message)

1. **Transcript or outline** — paste it (required)
2. **Content Intent** — pick one:
   - **Awareness** — broad hook, highly shareable, soft CTA
   - **Consideration** — problem-solving, high informational value
   - **Conversion** — direct-intent CTA (for ROH: donate / nominate / sign up / refer — never a hard real estate pitch)
   - **Authority/Trust** — deep expertise, contrarian take, market-data breakdown
3. **Primary subject** — the Foundation, a hero profession, a grant, a hero story, an educational topic, an event
4. **Lead magnet / resource URL** — the link the CTA drives to; if none, CTAs stay soft
5. **Geographic anchor** — default Wisconsin statewide; name specific cities if local
6. **Platforms wanted** — default is generate ALL (master copy); John can narrow at request time

If John pastes a transcript and names a subject, infer intent and proceed. Confirm the resource URL only if a Conversion CTA needs it.

## Output Structure

Deliver in this order with clear section headers:

### PART 1 — PRODUCTION & REPURPOSING ARCHITECTURE
- Content Intent Assessment (1-2 sentences on why this fits the chosen intent class)
- Repurposing Strategy (platform-native vs. raw repost vs. structural edit variations per app)
- Runtime targets per format
- First-3-seconds direction (the most critical production decision)
- B-roll / visual suggestions
- Thumbnail text (YouTube and Facebook)

### PART 2 — PLATFORM DEPLOYMENT PACK

For each platform, generate a fully native asset:

**Facebook Reel** — hook-first script adapted for Facebook's algorithm; 15-60 sec; caption with CTA
**Facebook Feed Post** — longer-form, story-driven; separate from the Reel
**Instagram Reel** — hook-first, visually driven; 7-30 sec preferred; caption with hashtags
**YouTube (Long-form SEO)** — full title, description with timestamps, tags, end screen CTA, pinned comment
**TikTok** — John posts this himself; hook-first, native TikTok voice, no formal CTA structure
**LinkedIn** — professional tone; longer caption acceptable; no hashtag spam

### PART 3 — OMNI-CHANNEL PACK
- YouTube Community Post
- GBP update (John posts manually)
- Email teaser (2-3 sentences + link)
